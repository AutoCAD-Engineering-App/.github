## Where It Starts
AutoCAD for Windows sits at the center of a lot of design work — architecture, mechanical engineering, civil projects, and more all lean on it at some point to turn a concept into a precise, measurable drawing. Using AutoCAD day to day usually means moving between 2D drafting for plans and details, and 3D modeling when a project needs to be visualized before it's built. Drawings live in the DWG file format, so they travel cleanly to the next person or the next tool in the pipeline.

> Good drafting software tends to disappear into the background of the work — the fewer times you think about the tool itself, the more attention is left for the design.

> **Tip:** Save early drafts under clear layer names — future you will thank present you when a drawing grows more complex.

## What You'll Find Once You're In
Once you're inside AutoCAD, a handful of tools tend to matter most for everyday work.

* Precise 2D drafting with exact measurements and annotations
* 3D modeling for visualizing parts and structures before they're built
* Native DWG file support for sharing drawings across the design industry
* Customizable toolsets and commands that adapt to different design disciplines

## What It Asks of Your Machine
AutoCAD wants a supported 64-bit version of Windows and runs most comfortably on a modern multi-core processor, with enough memory to comfortably clear Autodesk's current minimum recommendation — 3D work in particular benefits from the extra headroom. Give it enough free disk space for installation plus room for drawing files, and leave a bit more as your project library grows over time.

## Questions People Tend to Ask
Is AutoCAD free? No — AutoCAD is commercial, subscription-based software from Autodesk, not a free download; Autodesk does offer a free trial period, and free AutoCAD access is available to eligible students and educators through Autodesk's education program. Which versions of Windows are supported? AutoCAD runs on recent 64-bit versions of Windows — check Autodesk's current requirements before installing on an older machine. Can I share DWG files with people using other CAD tools? Yes, DWG is a widely supported format across the CAD industry, though exact compatibility can vary by tool and version.

## How It's Licensed
AutoCAD is commercial, subscription-based software published by Autodesk, not an open-source or free-to-keep product.
